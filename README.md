# Cultivation RPG

Development setup for a web 2D incremental RPG. Gameplay and GDD are pending design approval.

## Requirements

- Node.js 20.19+ or 22.12+ (Node 24 supported)
- npm

## Commands

```bash
npm install
npm run dev
npm run test
npm run lint
npm run build
```

`dist/` is the static build output for Cloudflare Pages. No backend is needed for the MVP.
